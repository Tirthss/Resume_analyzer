# Resume_analyzer
PBL-1
## Setup
1. Download dataset from Kaggle: https://www.kaggle.com/datasets/gauravduttakiit/resume-dataset
2. Run: pip install -r requirements.txt
3. Run: python add_tech_categories.py
4. Run: python balance_dataset.py  
5. Run: python train_model.py
6. Run: streamlit run app.py
